# 로우앤프리 (Low & Free)

'제로'에 속지 않는, 진짜 저당의 시작.

원재료명을 사진/텍스트로 분석해서 인공감미료·대체당의 종류와 안전 수치, 부작용을 알려주는 웹앱입니다.

## 주요 기능

- 27종 감미료 데이터베이스 (인공감미료·당알코올·천연 대체당·천연당류)
- 사진 OCR 분석 (Tesseract.js)
- 텍스트 입력 분석
- 일일 섭취 기록
- 출처가 명시된 안전 정보

## 데이터 출처

식약처 식품첨가물공전, JECFA (FAO/WHO), EFSA, US FDA, IARC Monographs, 대한당뇨병학회 등 국내외 공인 기관 자료를 바탕으로 구축.

## 개발 중

빌드인 퍼블릭(Build in Public)으로 만들어가는 1인 MVP 프로젝트입니다.
